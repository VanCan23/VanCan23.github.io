# VanCan23.github.io

This is my personal portfolio website hosted on GitHub Pages.

## 🌐 Live Site
Visit the portfolio at: https://vancan23.github.io/

## 📝 Customization Guide

To personalize your portfolio, update the following in `index.html`:

### Contact Information
- **Email**: Replace `your.email@example.com` with your actual email address (line 112)
- **LinkedIn**: Replace `https://linkedin.com/in/yourprofile` with your LinkedIn profile URL (line 114)

### Projects
Update the project cards (lines 84-103) with:
- Your actual project titles
- Project descriptions
- Links to live demos or GitHub repositories

### About Section
- Customize the "About Me" text to reflect your background and interests (lines 32-35)

### Skills
- Modify the skills lists (lines 44-75) to match your actual technical skills

### Hero Section
- Update the tagline "Web Developer & Creative Problem Solver" to reflect your role (line 24)

## 🎨 Styling
The `style.css` file contains all the styling. You can customize:
- Colors in the `:root` CSS variables
- Fonts and typography
- Layout and spacing

## 🚀 Deployment
This site is automatically deployed via GitHub Pages when you push to the main branch.
